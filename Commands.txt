Random requests:
cat: gives a random image of a cat
duck: gives a random image of a duck
joke: gives a random dad joke

!events:
!events: gives the events lists in numbered order
!addevent (event name) date (event date): adds an event to events list (date must be filled out)
!delevent (event index): removes an event from the events list (event index is refering to the number given with events list)

!status: will give the current status of the minecraft server
!start: will start up the minecraft server
!stop: stops the minecraft server (private)
!ip: gives the minecraft server ip

!gamba: will give you all the gambling commands
